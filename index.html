🦠 Ameba Earth

東京の気温に翻弄される小さな命達

A Squishy Artificial Life Simulation

📖 概要 / About

Javaで作られた、ぷにぷに動く人工生命シミュレーション。 最大の特徴は「現実世界とのリンク」。リアルタイムの東京の気温を取得し、アメーバたちの生態系や食料事情が変化します。 物理演算で描かれる、美しくも過酷な「小さな地球」を観察してみませんか？

A Java-based artificial life simulation featuring squishy amoebas that move with soft-body physics. The unique feature is "Real-World Integration" - fetching real-time Tokyo temperature data to affect the amoebas' ecosystem and food availability. Observe this beautiful yet harsh "tiny Earth" rendered with physics simulations!

✨ Features

Soft-Body Physics
Amoebas are modeled as spring-mass systems with internal pressure, giving them a squishy, organic feel.
Metaball Rendering
Uses radial gradients and thresholding to render smooth, merging blobs.
Evolutionary Genetics
Each amoeba has genes for speed, sense radius, metabolism, and color. Offspring inherit and mutate these traits.
Complex Behaviors
Foraging, predation ("Weak Eat Strong"), flocking with cohesion and alignment, asexual reproduction.
IoT Integration
Real-time temperature data (via Open-Meteo API) influences the environment (e.g., food spawning rates).
Character Polish
Amoebas feature expressive eyes that track their movement and a visible nucleus.
High Performance
Optimized with a Spatial Grid and Physics Sub-stepping to support fast-paced simulation (5x time scale).

⚙️ 必要環境 / Requirements

  • Java Development Kit (JDK): Version 11 or higher
  • OS: Windows, macOS, or Linux

🚀 実行方法 / How to Run

方法1: JARファイルを実行

  1. Releasesページから AmebaEarth.jar をダウンロード
  2. ダブルクリックで実行（Javaがインストールされている必要があります）

方法2: ソースコードからコンパイル (Windows)

  1. プロジェクトディレクトリに移動
  2. compile_and_run.bat をダブルクリック、またはコマンドラインから実行

🎮 遊び方 / Controls

シミュレーションは自動的に実行されます。アメーバたちが進化し、群れ、競争する様子をご覧ください！

The simulation runs automatically. Watch the amoebas evolve, swarm, and compete!

📁 Project Structure

  • src/Main.java: Entry point, game loop, and rendering setup
  • src/Simulation.java: Core logic for physics, entity management, and spatial grid
  • src/Renderer.java: Handles metaball rendering and character drawing
  • src/IoT.java: Fetches real-time weather data
